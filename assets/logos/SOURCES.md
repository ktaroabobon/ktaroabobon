# Logo sources and licenses

The tech stack images in `assets/stack/` are built from the files in this
folder by `scripts/build_stack.py`. All logos are trademarks of their
respective owners. They are used here only to name the technologies the
profile owner works with, and no endorsement is implied.

## Changes made to the files

- The build script embeds each file as is. It changes colors only for
  Three.js, Flask and Prisma on the dark theme, where black is drawn as white.
- On the dark theme, the Django, MySQL, OpenAI and Anthropic logos are kept
  unchanged and placed on a light tile.
- `shell.svg` and `shell-dark.svg`: the Adobe Illustrator editing data
  (`<foreignObject>` and `<i:pgf>`) was removed. The drawing is unchanged.
- `drizzle.svg` and `drizzle-dark.svg`: the build script uses only the mark
  (the four bars) and leaves out the wordmark.
